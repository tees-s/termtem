# termTem · ระบบเตรียมสอบกลางภาค 2/2569 (ป.6)

ระบบช่วยวางแผน ทบทวนเนื้อหา ตารางสอบ เช็กลิสต์ และแบบฝึกหัดลองทำข้อสอบกลางภาค ชั้นประถมศึกษาปีที่ 6

### โครงสร้างไฟล์หลัก
- `index.html` : หน้าแรก (สรุปตารางสอบ นับถอยหลัง และเช็กลิสต์ประจำวัน)
- `plan.html` : หน้ารายการเช็กลิสต์ทุกวิชาแบบละเอียด
- `quiz.html` : ระบบทำแบบทดสอบและเฉลยรายวิชา
- `q/` : คลังข้อสอบรายวิชา (ภาษาไทย, คณิต, วิทย์, สังคม, ประวัติศาสตร์, ภาษาอังกฤษ, ภาษาจีน, CSI)
